# Security

`git shuttle ui` runs commands in your repositories, so its security matters. The model is described in
[docs/ui.md](docs/ui.md#security-model).

## Supported versions

Only the latest release receives fixes.

| Version | Supported |
|---|---|
| 0.3.x | yes |
| older | no: update with `git shuttle update` |

## Reporting a vulnerability

Please do not open a public issue. Use the private vulnerability reporting of the repository:
[report a vulnerability](https://github.com/adityaoryza/git-shuttle/security/advisories/new) (on the repository page: **Security**, then **Report a vulnerability**). Include the version (`git shuttle --version`), what you did and what happened.
Reports are answered within a week.
