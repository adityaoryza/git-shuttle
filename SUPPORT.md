# Support

Thanks for using `git-shuttle`.

## Questions and usage help

- Read the [README](README.md) for install and command usage.
- Read [docs/ui.md](docs/ui.md) and [docs/architecture.md](docs/architecture.md) for UI and architecture details.
- If you still need help, open an issue and include:
  - `git shuttle --version`
  - `git --version`
  - OS and shell details
  - steps to reproduce

## Bug reports

Please use the [bug report issue template](.github/ISSUE_TEMPLATE/bug_report.md) and include command output (with private data removed).

## Security reports

Do **not** open public issues for vulnerabilities.
Follow the private reporting flow in [SECURITY.md](SECURITY.md).
